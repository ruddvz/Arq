ARQ LOGO ESSENTIALS - FINAL

This ZIP contains only final production files. No drafts, references, QA screenshots or archived versions are included.

01_VECTOR: SVG and RGB vector PDFs for Canva, Figma, websites, presentations and placed artwork.
02_4K_PNG: transparent Tight and ClearSpace PNG exports.
03_WEB: multi-size favicon, SVG favicon, PWA icons, maskable icon, manifest and Open Graph image.
04_APP_ICONS: 1024 px black and Phthalo Green app icon sources.
05_PRINT: generic DeviceCMYK vector PDFs. Ask the printer for an ICC profile before a large run.

Primary colours: Black #000000, White #FFFFFF, Phthalo Green #0B6B50.
Minimum sizes: wordmark 64 px / 18 mm, symbol 24 px / 7 mm, tagline lockup 360 px / 90 mm.
The a and q share the exact same bowl path and gap. The q adds only the descender.
