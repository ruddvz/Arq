# Product requirements

## Product

Arq is a browser-based architectural plan and lightweight BIM editor.

## First user

Independent architects and practices of approximately 1 to 10 people working on
residential, renovation, interior and small commercial projects.

## First job

Create or trace a small plan, edit semantic walls and openings, maintain rooms,
inspect properties, see coordinated 3D, add dimensions and export a scaled PDF.

## Required outcomes

- New user completes the benchmark workflow without external instruction.
- Wall edits update plan, 3D, rooms, openings and dependent dimensions.
- Every invalid operation leaves the project unchanged.
- Work survives abnormal browser termination.
- Project archive can be downloaded and reopened.
- PDF uses vector linework and preserves scale.
- The supported benchmark project meets performance targets.

## Core requirements

- Stable IDs
- Type and instance properties
- Typed model operations
- Undo and redo
- Local journal and snapshots
- Plan-first semantic model
- Renderer-independent project data
- Explicit validation messages
- Light monochrome interface
- Keyboard, mouse, trackpad, touch and Pencil input model
- Open export and local archive

## Claims not permitted

- Full AutoCAD replacement
- Full Revit replacement
- Lossless IFC
- Native RVT compatibility
- Survey-grade LiDAR
- Code approval
- Structural safety
- Permit-ready automatic design
