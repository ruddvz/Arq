# UI microcopy checklist

- Does the label name the object or action?
- Is it sentence case?
- Is the same tool named the same way elsewhere?
- Is a search synonym accidentally becoming a second visible label?
- Does a disabled control explain why?
- Is the action current, planned, or unavailable?
- Is local save distinct from sync?
- Is "recovered" tied to a recovery source?
- Does failure copy state what remains safe?
- Does a destructive action name what will be deleted/replaced?
- Does import/export copy report omissions?
- Does AI remain a proposal until applied?
- Is a stable error code secondary to human explanation?
- Does the instruction work without colour or screen position?
