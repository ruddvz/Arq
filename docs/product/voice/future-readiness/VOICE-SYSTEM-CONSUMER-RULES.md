# Rules for anything that consumes the Arq voice system

Applies to:

- support bot;
- product AI;
- docs generator;
- marketing generator;
- UI copy generator;
- release-note generator;
- onboarding assistant;
- code agent modifying visible copy.

## Consumers must

- use canonical visible names;
- preserve state distinctions;
- consult claim state;
- check freshness for volatile/current facts;
- expose uncertainty;
- preserve professional boundaries;
- use the same error taxonomy;
- use the same role names;
- use the same format/fidelity vocabulary.

## Consumers must not

- maintain their own independent feature list;
- invent pricing;
- infer shipping status from a design registry;
- infer product support from a parser/package alone;
- turn “planned” into present tense;
- call local save sync;
- call a proposal an applied change;
- treat file integrity as design correctness;
- resolve conflicting sources by guessing.

## Output-level rule

A consumer may simplify wording.

It may not simplify meaning.
