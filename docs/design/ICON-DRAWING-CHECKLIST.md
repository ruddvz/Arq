# Icon drawing checklist

- 24 by 24 viewBox
- 20 by 20 compact test
- 1.75 px standard stroke
- Round caps
- Round joins unless technical meaning requires a mitre
- Optical alignment
- No embedded colour
- No fill except active inversion
- Understandable at 16 px
- Accessible name
- Default, hover, active, disabled and selected state
- Test at 1x and high-density displays
- Test next to Plus Jakarta Sans labels
- Recognition test with architects
