# Design system

## Direction

Arq should look like a professional instrument.

- Monochromatic application chrome
- Light appearance first
- Plus Jakarta Sans
- JetBrains Mono for dimensions and coordinates
- 4-point spacing grid
- Small radii
- Functional motion
- No decorative gradients
- No glass effects
- No excessive cards or pills

## Important boundary

The interface is monochromatic. The building model may use materials, imported
colours, analytical overlays and optional collaboration accents.

## Status

Status must use icon, text, pattern and line treatment. Hue cannot be the only signal.
