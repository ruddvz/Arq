# Keyboard shortcuts

Proposed baseline:

- V Select
- W Wall
- M Move
- R Rotate
- O Offset
- Escape Cancel
- Enter Confirm
- Space Temporary pan
- Tab Cycle candidate or field
- Cmd or Ctrl Z Undo
- Cmd or Ctrl Shift Z Redo
- Cmd or Ctrl K Command palette
- F Fit selection
- Shift F Fit project

Final shortcuts require browser-conflict and architect testing.
