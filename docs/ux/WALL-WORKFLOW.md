# Wall workflow

1. Select wall type.
2. Select alignment.
3. Place start.
4. Preview.
5. Enter distance or place end.
6. Continue chain or finish.
7. Preview join.
8. Validate.
9. Commit typed operation.

Initial joins:

- butt;
- mitre;
- T;
- cross;
- disallow join.

The wall is defined by semantic reference line, type, thickness, level, height,
alignment, join intent and hosted openings.
