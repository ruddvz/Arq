# iPad interaction

Pencil:

- precise selection;
- drawing;
- hover preview;
- handles;
- annotations.

Finger:

- pan;
- pinch zoom;
- orbit;
- broad selection;
- panels.

Keyboard and trackpad:

- shortcuts;
- numeric input;
- command palette;
- precision navigation.

Portrait uses a resizable inspector sheet. Landscape uses a side inspector.
