# Onboarding

The first project tutorial must be skippable.

Teach through the benchmark workflow:

1. Create project.
2. Draw exterior wall chain.
3. Add internal wall.
4. Place door.
5. Place window.
6. Create room.
7. Add dimension.
8. Open 3D.
9. Move wall and observe coordinated updates.
10. Export PDF.

Do not use a long product tour before the user reaches the canvas.
