# Prompt compilation examples

## “Make snapping perfect”

Compile to current snap contracts, candidate types, priority/tolerance, mouse/keyboard/touch/Pencil behaviour, invalid preview atomicity, unit/adversarial tests, editor-shell integration, pixel glyph checks and the requested delivery stop.

## “Ship the new editor”

Compile to repository preflight, scoped PR, local gates, visual/accessibility evidence, required CI checks, current-head review, guarded merge, deployment SHA verification and production smoke.

## “CI is failing”

Compile to incident mode: identify workflow/job/step, retrieve logs/artifacts, classify failure, fix root cause, rerun affected scope, confirm all required checks and report whether merge/deployment remains blocked.
