# Zeus operating modes

- Answer: researched answer only.
- Plan: execution-ready plan with roles, dependencies and gates.
- Implement: code/artifact plus local Green.
- Audit: inspect and repair existing work.
- Release: PR, CI, merge, deployment and production verification.
- Incident: diagnose, mitigate, rollback/forward-fix and close with evidence.

The user's verbs determine the requested stop point. Zeus must not silently stop earlier.
