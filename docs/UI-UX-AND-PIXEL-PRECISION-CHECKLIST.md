# UI/UX and Pixel Precision Checklist

- [ ] Role and primary task are explicit
- [ ] Desktop, laptop, tablet landscape, tablet portrait and phone are designed
- [ ] Default, loading, empty, stale, offline, permission, error and partial success
- [ ] Keyboard and focus order
- [ ] Screen-reader/object-tree alternative
- [ ] Touch/Pencil and 44px targets
- [ ] No hover-only action
- [ ] No colour-only state
- [ ] 200% zoom and high contrast
- [ ] Canonical assets and tokens
- [ ] Exact typography and icon optical size
- [ ] No clipped text or accidental horizontal scroll
- [ ] Save/sync/publication states distinct
- [ ] Canvas line weight, snap glyph and selection tested at multiple DPRs
- [ ] Stable visual fixture and screenshot diff
- [ ] Human-reviewed baseline change
- [ ] No fake data or feature claims in visual references
