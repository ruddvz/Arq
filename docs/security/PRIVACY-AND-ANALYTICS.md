# Privacy and analytics

Do not collect by default:

- project names;
- addresses;
- raw geometry;
- sheet content;
- client names;
- raw AI prompts.

Collect where necessary:

- tool;
- result code;
- latency;
- crash;
- recovery;
- export type;
- coarse model tier;
- command search with no result.

Support diagnostics must require explicit user consent before including model content.
