# External Executor Handoff

A Zeus 3.0 handoff is a complete delivery packet:

1. accountable role and reviewers;
2. current repository evidence and base/head state;
3. accepted architecture/policy;
4. relevant Arq invariants;
5. outcome/current state;
6. scope/non-goals;
7. owned files/contracts and dependency wave;
8. binary acceptance;
9. local verification;
10. GitHub/CI gates;
11. merge/deployment/production stop point;
12. security/rollback;
13. Senior Quality Gate;
14. exact handoff/status format.

Include task-critical facts inline. Never invent a branch, agent, package version,
required check, deployment provider or passing result.
