# Arq Domain and Delivery Playbooks

## Product and architecture
Workflow, release scope, ADRs, ownership, canonical/derived data, migration and non-goals.

## Semantic BIM and operations
Identity, type/instance, level/host, relationships, validation, inverse, deletion,
serialization, projections and adversarial tests.

## Geometry and constraints
Coordinate space, units status, tolerance, deterministic predicates, degeneracy,
mutation boundary, properties and performance.

## Editor and input
Command lifecycle, screen/world conversion, selection/snap, numeric entry,
mouse/keyboard/touch/Pencil, focus, cancellation and undo.

## Rendering and performance
Protected scene, comparable workload, environment, samples, percentiles, memory,
startup, fidelity, degradation and limitations.

## ArqFS, sync and recovery
Versions/features, working copy, transaction, clean export, copy-on-write migration,
semantic hash, crash/quota/corruption, idempotency, conflict and rollback.

## Interoperability
Subset/version, units/coordinates, provenance, resource limits, loss report, fixtures
and round trip.

## UI/UX and visual system
Role, primary task, complete states, responsive capability, keyboard/focus, canvas
alternative, touch/Pencil, recovery, performance and visual regression.

## Security and supply chain
Trust boundary, authorization, secrets, parser limits, dependencies/licenses, CI token
permissions and release provenance.

## AI and ArqScript
Request/context, assumptions, typed operations, preconditions, affected IDs,
validation, diff, transaction, revision, undo and prohibited claims.

## QA and release
Risk-appropriate local gates, PR evidence, CI logs/artifacts, merge guard, deployment
identity, production smoke, rollback and incident closure.
