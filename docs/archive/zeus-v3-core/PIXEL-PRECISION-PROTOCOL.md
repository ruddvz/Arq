# Pixel Precision Protocol

Pixel precision begins during contract compilation, not after implementation.
It is measurable fidelity across design, interaction, accessibility and rendering.

## Authority

1. canonical brand/logo assets;
2. approved tokens;
3. component/page behaviour specs;
4. exact reference composition;
5. high-resolution detail reference;
6. supplemental concept.

A screenshot never overrides permissions, content truth, model semantics or responsive behaviour.

## Contract requirements

Before coding define:

- component/page ID and role;
- viewport/capability matrix;
- token sources;
- exact content and data fixture;
- component interaction states;
- grid/alignment and minimum/maximum dimensions;
- overflow/wrapping/truncation rules;
- canvas/overlay/z-order rules;
- animation/reduced-motion behaviour;
- visual-regression fixtures and allowed dynamic masks.

## Stable environment

Record browser/version, OS, viewport CSS size, DPR, zoom, fonts/build, theme, locale,
contrast/reduced motion, fixture and animation stabilization.

## Minimum matrix

Use the current support matrix. Otherwise include 1440×900, 1280×800, 1194×834,
834×1194, 390×844, 360×800, 200% zoom, high contrast and reduced motion.

## Precision checks

- token spacing, typography, radii, borders, shadows and focus rings;
- canonical icon stroke/optical size;
- logo clear space/minimum size;
- no clipping, accidental scroll, overlap or one-pixel drift;
- layout remains usable with realistic long text and data;
- complete states and correct transition visuals;
- safe areas and 44px touch targets;
- canvas line weight at supported zoom/DPR;
- snap glyph centering, selection handles and text baseline;
- export-versus-viewport fidelity;
- plan/3D identity and no stale projection.

## Visual regression

- deterministic fixtures;
- before/after/diff artifacts;
- no unreviewed structural diff in critical components;
- tiny anti-aliasing threshold only when documented;
- baseline changes require explanation and reviewer approval;
- never update a baseline to hide wrong copy, missing controls, clipping or contrast.

## Handoff evidence

Provide matrix, screenshots/diffs, token/asset source, browser/font limitations,
accessibility result, reviewer decision and any accepted deviation.
