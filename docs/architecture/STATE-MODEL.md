# State model

UI state:

- panels;
- active mode;
- tool;
- hover;
- menus;
- camera;
- temporary preview.

Project state:

- semantic entities;
- views;
- sheets;
- annotations;
- imports;
- revision.

Derived state:

- room boundaries;
- meshes;
- spatial indexes;
- validation;
- thumbnails.

The project model must not live inside React component state.
