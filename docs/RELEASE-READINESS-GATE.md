# Release Readiness Gate

A release cannot be Green until relevant evidence exists for locked scope/decisions,
local tests/build, geometry adversarial fixtures, `.arq` create/open/export/reopen,
migration/recovery, visual regression, accessibility/device matrix, performance
budgets, import/export loss reports, security/resource limits, PR current-head checks,
required reviews, post-merge workflow, deployment identity, production smoke,
telemetry observation and rollback.

A local mockup, headless benchmark, successful build or provider “ready” status alone
is not production certification.
