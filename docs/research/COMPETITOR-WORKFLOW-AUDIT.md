# Competitor workflow audit

Audit the same benchmark task in:

- AutoCAD
- Revit
- Archicad
- SketchUp
- Shapr3D
- FreeCAD or Bonsai where relevant

Benchmark task:

1. Create a two-room plan.
2. Add exterior and interior walls.
3. Place two doors and three windows.
4. Add room names and areas.
5. Add dimensions.
6. Open 3D.
7. Move one wall.
8. Export PDF.
9. Reopen.
10. Recover from an invalid action.

Record:

- number of commands;
- modes;
- dialogs;
- hidden settings;
- failure messages;
- automatic changes;
- time;
- keyboard dependence;
- discoverability;
- output quality;
- recovery behaviour.

Do not copy competitor interface or icons.
