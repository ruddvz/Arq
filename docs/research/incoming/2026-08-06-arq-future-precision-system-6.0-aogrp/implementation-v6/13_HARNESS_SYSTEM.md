# ARQ harness system

The harness has six layers:

1. Byte conformance: signatures, roots, segments, hashes.
2. Semantic conformance: objects, units, operations, revisions.
3. Failure harness: crashes, truncation, corruption, resource exhaustion.
4. Differential harness: independent readers and materialisers.
5. Product harness: open, edit, save, reopen, export, recover.
6. Automation harness: MCP grant, proposal, preview, approval, commit, undo.

Every released claim maps to one or more harness cases and immutable evidence.
