# Decision sequence

1. Confirm current format and invariants.
2. Accept or reject storage-independent canonical object model.
3. Select deterministic encoding.
4. Allocate experimental format profile.
5. Build two readers.
6. Prove migration of a small fixture.
7. Prove crash recovery and repack.
8. Benchmark browser and native reads.
9. Decide whether AOGRP becomes production format, optional interchange, or internal sync representation.
