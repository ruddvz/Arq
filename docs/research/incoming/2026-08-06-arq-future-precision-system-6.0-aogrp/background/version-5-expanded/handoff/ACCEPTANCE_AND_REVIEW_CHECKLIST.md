# Acceptance and review checklist

- [ ] Immutable HEAD and working tree recorded.
- [ ] Repository instructions and ZEUS files read.
- [ ] Existing `.arq` IDs and migrations inventoried.
- [ ] Storage authority ADR accepted.
- [ ] Current tests run before changes.
- [ ] No parallel operation or evidence system introduced.
- [ ] Source file retained during migration and repair.
- [ ] Candidate opened through a fresh reader.
- [ ] Invalid candidate leaves previous destination unchanged.
- [ ] Unknown required capabilities block editing.
- [ ] Unknown optional records follow their preservation class.
- [ ] Browser and mobile failure states tested.
- [ ] Public status contradiction corrected.
- [ ] Claims remain scoped to verified evidence.
- [ ] Rollback documented.
- [ ] Delivery stops before unauthorised commit, PR, merge, or deployment.
