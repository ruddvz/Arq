# Large-model partitioning

Partition by project ownership and semantic boundaries, not arbitrary byte chunks. Federated references pin project ID, revision, hash, transform, coordinate reference system, capability requirements, access policy, and fallback. Spatial indexes and LOD are derived. Partial loading cannot permit an edit whose preconditions depend on unloaded authoritative objects unless the operation explicitly declares and validates the dependency.

## Mandatory evidence

A production claim requires repository tests, revision-bound artefacts, and failure-path verification. Package-local demonstrations are informative only.
