# Browser compatibility profile

Supported browser claims require tested versions, OPFS capability, Web Locks or equivalent writer ownership, file picker behaviour, worker support, WASM memory behaviour, quota handling, background suspension, mobile acquisition, and recovery. A fallback may be read-only or reduced-function, but the UI must say so before editing.

## Mandatory evidence

A production claim requires repository tests, revision-bound artefacts, and failure-path verification. Package-local demonstrations are informative only.
