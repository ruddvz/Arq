# Geometry kernel adapter

The adapter accepts normalised recipes, local coordinate frames, tolerances, stable semantic IDs, cancellation, and resource budgets. It returns success or typed diagnostics, validated topology, lineage from input features to outputs, bounds, mass properties where supported, and derived tessellation. It must never expose transient kernel pointers as stable IDs. Kernel upgrades require corpus replay and payload invalidation policy.

## Mandatory evidence

A production claim requires repository tests, revision-bound artefacts, and failure-path verification. Package-local demonstrations are informative only.
