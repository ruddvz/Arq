# Domain-pack ABI

A domain pack declares namespace, semantic schemas, operation schemas, validators, derived generators, interchange mappings, UI descriptors, migration functions, dependencies, permissions, and test fixtures. ABI compatibility is explicit. Core remains responsible for IDs, revisions, transactions, permissions, persistence, evidence, and safe failure.

## Mandatory evidence

A production claim requires repository tests, revision-bound artefacts, and failure-path verification. Package-local demonstrations are informative only.
