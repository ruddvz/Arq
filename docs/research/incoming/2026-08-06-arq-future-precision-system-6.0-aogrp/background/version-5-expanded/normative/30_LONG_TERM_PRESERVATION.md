# Long-term preservation

A preservation profile stores canonical project records, schema and capability manifests, required assets, migrations or migration descriptors, publication evidence, human-readable summaries, and interchange reports. It excludes disposable caches. The package should support a future archival export containing a clean `.arq`, manifest, detached hashes, rendered PDF, selected neutral exchange files, and a preservation report.

## Mandatory evidence

A production claim requires repository tests, revision-bound artefacts, and failure-path verification. Package-local demonstrations are informative only.
