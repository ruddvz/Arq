# Release profile

A format release names repository commit, accepted ADRs, schema registry snapshot, application ID, user version, migration graph, supported capabilities, conformance profiles, fixtures, reference readers, security review, browser matrix, interchange profiles, documentation, rollback, and support window. A green build alone is not a format release.

## Mandatory evidence

A production claim requires repository tests, revision-bound artefacts, and failure-path verification. Package-local demonstrations are informative only.
