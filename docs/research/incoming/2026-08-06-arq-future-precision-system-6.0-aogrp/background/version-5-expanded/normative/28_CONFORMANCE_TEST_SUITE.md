# Conformance test suite

Conformance is profile-based. Reader Core tests identity, header, required tables, capabilities, canonical hashes, resource limits, and preserving read-only behaviour. Writer Core adds atomic operations, revisions, source-preserving migration, and portable publication. Precision adds quantities, frames, tolerances, features, and selector states. AI adds grants, proposals, review, replay protection, and audit. Interchange profiles are separate and name exact external editions.

## Mandatory evidence

A production claim requires repository tests, revision-bound artefacts, and failure-path verification. Package-local demonstrations are informative only.
