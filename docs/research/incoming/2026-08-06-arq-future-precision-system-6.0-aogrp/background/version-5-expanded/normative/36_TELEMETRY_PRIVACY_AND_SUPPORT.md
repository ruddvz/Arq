# Telemetry, privacy, and support

Telemetry is optional, minimised, and separated from canonical project content. Never send model geometry, file bytes, names, addresses, comments, prompts, or assets by default. Diagnostics use codes, versions, timing buckets, browser capabilities, and redacted counts. Support bundles are user-reviewed, scoped, and generated as separate files.

## Mandatory evidence

A production claim requires repository tests, revision-bound artefacts, and failure-path verification. Package-local demonstrations are informative only.
