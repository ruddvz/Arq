# Resource URI model

Recommended URIs include `arq://project/{id}/revision/{root}/summary`, `arq://project/{id}/revision/{root}/objects/{objectId}`, `arq://proposal/{id}`, `arq://task/{id}`, and `arq://interchange-report/{id}`. Every project resource is revision-pinned. Unpinned aliases are convenience pointers and cannot be used as commit preconditions.
