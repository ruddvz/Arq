# SQLite 3.53.4 and WASM pin

Current upstream SQLite is 3.53.4. The repository should pin an exact source ID and build configuration, not merely “latest”. Evaluate the 3.53 WAL reset corruption fix, OPFS and OPFS Web Locks VFS behaviour, compile options, trusted schema, defensive mode, extension loading, limits, backup API, VACUUM INTO, session extension, and browser support. Package-local Python tests use 3.46.1 and are not substitution evidence.
