# Observability and support evidence

## Local diagnostic event

- event code and schema version;
- project-scoped pseudonymous reference where needed;
- application build and platform;
- workflow phase;
- duration and resource counters;
- structured diagnostic codes;
- no project geometry, prompts, paths, tokens, or personal data by default.

## Support bundle

The user selects included categories and sees a preview. The bundle may include redacted identity, format versions, capability list, diagnostic events, publication evidence, migration reports, and selected screenshots. Project content and assets are excluded unless explicitly selected.

## Operational dashboards

Dashboards distinguish parser failures, unsupported capability rates, publication failures by phase, recovery outcomes, migration failures, MCP denied actions, geometry regeneration failures, and browser storage pressure. Metrics do not establish correctness without fixture and revision evidence.
