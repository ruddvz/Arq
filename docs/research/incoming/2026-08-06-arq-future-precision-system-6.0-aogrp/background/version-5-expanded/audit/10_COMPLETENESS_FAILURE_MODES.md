# Completeness failure modes

A large package can still be incomplete if it lacks closure mechanics. Version 5 uses these tests:

- Every architecture proposal has an authority state.
- Every blocker has closure evidence.
- Every claimed artefact exists in the inventory.
- Every schema is meta-validated.
- Every fixture has an expected verdict.
- Every executable claim is generated from current test output.
- Every external current-version statement has an official source and observed date.
- Every production identifier is either repository-derived or explicitly unallocated.
- Every destructive workflow preserves rollback or source retention.
- Every AI write path uses grants, preconditions, validation, review, and audit.
