# Claim and language audit

Do not publish these claims without scoped evidence:

- lossless
- industry standard replacement
- manufacturing ready
- code compliant
- structurally safe
- flightworthy
- secure
- accessible
- corruption proof
- works offline everywhere
- supports all IFC, DWG, STEP, Revit, or USD files
- deterministic across every platform
- professionally approved

Preferred evidence language:

- “Opened read-only while preserving unknown optional records.”
- “Validated against IFC 4.3.2.0 Reference View fixture set X.”
- “Produced identical canonical roots in pinned Rust and TypeScript implementations on listed platforms.”
- “Recovered acknowledged operation groups in the tested crash scenarios.”
- “Analysis result generated by solver X with version, inputs, mesh, tolerance, and convergence evidence.”
