# Test and evidence gap audit

Package-local unit tests prove only the demonstration code in this ZIP. They do not prove browser, repository, deployment, or professional behaviour.

## Missing high-value evidence

- Independent reader and writer.
- Rust and TypeScript canonical hash parity.
- Browser OPFS crash and multi-tab tests.
- Safari iPhone acquisition and reopen after full hydration.
- Power-loss and quota-exhaustion injection.
- Migration from every supported production schema.
- Geometry kernel determinism and lineage corpus.
- Large city and assembly memory budgets.
- Real MCP SDK interoperability.
- Third-party IFC and STEP validation.
- Accessibility testing with keyboard and assistive technology.
- Production deployment provenance and rollback.

Each future claim must name its test scope and evidence location.
