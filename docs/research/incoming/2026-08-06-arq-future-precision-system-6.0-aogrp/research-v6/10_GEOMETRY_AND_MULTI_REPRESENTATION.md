# Geometry and multiple representations

A future `.arq` project needs several representations:

- semantic and parametric intent;
- exact analytic or B-Rep geometry where supported;
- subdivision or spline surfaces for industrial design;
- meshes for rendering and exchange;
- SDF or voxel fields for concept operations;
- procedural graphs for cities and repeated systems.

The file must declare which representation is authoritative for each object and how others were derived. Kernel payloads are codec-specific caches unless an accepted domain contract elevates them.
