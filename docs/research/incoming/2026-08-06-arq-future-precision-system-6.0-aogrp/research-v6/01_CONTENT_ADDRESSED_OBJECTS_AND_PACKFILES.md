# Content-addressed objects and packfiles

Git demonstrates that immutable content objects can be named by hashes, grouped into packfiles, indexed separately, delta-compressed, transferred efficiently, verified, repacked, and recovered without changing logical object identity. ARQ can borrow the object and pack separation, but must not copy Git's text-tree model blindly. Precision projects require stable semantic entity IDs, exact quantities, operation preconditions, capabilities, spatial partitions, and derived geometry.

Recommended lesson: content IDs identify immutable payloads; stable entity IDs identify design concepts across revisions; revision objects connect accepted state. Pack layout remains replaceable.
