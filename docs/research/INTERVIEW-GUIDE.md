# Architect workflow interview guide

## Purpose

Understand actual recent work, not an abstract feature wish list.

## Opening

- Tell me about the most recent small project you worked on.
- What information did you receive first?
- Show me how you began the project.
- Which software did you use at each step?

## Workflow

- How did you capture or receive existing conditions?
- What was the first drawing or model you created?
- Which actions did you repeat most?
- What did you have to redraw?
- Where did you leave the main application?
- Which files did you import and export?
- What did clients and consultants receive?
- Where did errors appear?
- What took longer than expected?

## Precision and trust

- Which dimensions must never change unexpectedly?
- Which automatic behaviours do you turn off or work around?
- When do you trust generated or imported data?
- What information must an import report contain?
- Which changes would you allow AI to propose?
- Which changes would you never allow AI to make automatically?

## Platform

- Which computers and tablets do you use?
- Do you use an iPad during authoring or only review?
- How often do you work offline?
- Which keyboard commands are essential?
- Do you use command-line drafting?

## Closing

- What would make you try a browser-based editor?
- What would stop you?
- May we test a prototype with you later?
